\# Merge Conflict Note



A merge conflict was deliberately created between `conflict-real-a` and `conflict-real-b`.



Both branches changed the same project description in `README.md` in different ways. When I merged `conflict-real-a` into `conflict-real-b`, Git reported a content conflict.



I opened `README.md` and resolved the conflict manually by removing the conflict markers and keeping the original project description.



The resolved changes were then staged and committed.



This exercise helped me practice identifying and resolving conflicting changes between Git branches.
